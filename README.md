# ☕ CoffeeTime Project

Це мій перший Java веб-проект, розроблений на Windows та деплоєний на Linux (Tomcat).

## 🚀 Технології
* **Java 21**
* **Maven** (збірка)
* **Tomcat 10** (сервер додатків)
* **Windows & Ubuntu (VirtualBox)**

## 🛠 Як запустити деплой
Щоб зібрати проект та відправити його на сервер, просто запустіть файл у корені проекту:
`GO.bat`

## 🔗 Посилання
Після успішного деплою сайт доступний за адресою:
[http://localhost:8888/coffeetime/](http://localhost:8888/coffeetime/)
